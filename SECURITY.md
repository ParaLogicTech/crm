# Security Policy

This repository is ParaLogic CRM, a Frappe app maintained by ParaLogic. We take security issues in it seriously.

## Reporting a vulnerability

Please don't open a public issue. Report it privately through
[GitHub's private vulnerability reporting](https://github.com/ParaLogicTech/crm/security/advisories/new)
(Security tab → "Report a vulnerability").

Include the affected branch and commit, steps to reproduce and the impact you expect. We'll acknowledge the report,
keep you updated, and credit you in the advisory if you'd like.

## Issues that also affect Frappe or ERPNext

crm was split out of ERPNext, and it runs on ParaLogic's frappe fork. If the issue also exists in stock
[ERPNext](https://github.com/frappe/erpnext) or [Frappe](https://github.com/frappe/frappe), please report it to
Frappe as well, following [Frappe's security policy](https://frappe.io/security). Issues in the frappe fork itself go
to [ParaLogicTech/frappe](https://github.com/ParaLogicTech/frappe/security/advisories/new).

## Supported versions

Only the `version-15` branch receives security fixes.
